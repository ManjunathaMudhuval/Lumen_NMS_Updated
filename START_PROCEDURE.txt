NMS_APP - Complete Start/Stop Procedure (Beginner Friendly)
=============================================================
IMPORTANT UPDATE: The app now runs on A SINGLE PORT (8091).
The backend (API) now also serves the frontend (website) files, so you
do NOT need to start two separate servers anymore. This avoids the
"backend unreachable / inventory not loading" problem that happened
when only one of the two ports was reachable from the browser.

IMPORTANT NOTE ABOUT RUNNING SCRIPTS:
Always type "bash run_backend.sh ..." (with the word "bash" in front).
Typing just "run_backend.sh start" WITHOUT "bash" in front will fail with:
    bash: run_backend.sh: command not found
This is normal Linux behavior (current folder is not in $PATH). Always
use the full command exactly as written below, e.g.:
    bash run_backend.sh start


====================================================
STEP 0: Open a terminal (bash)
====================================================
- Open VS Code.
- Open a terminal: Menu > Terminal > New Terminal
  (or press Ctrl + ` backtick key)
- You should see a prompt like:
      [username@machine NMS_APP]$
- This is "bash". Every command below is typed here, then press Enter.


====================================================
STEP 1: Start the App (backend + frontend together)
====================================================
Type:
    cd /home/ad39013/NMS_APP/backend
    bash run_backend.sh start

Expected output:
    Backend started on http://127.0.0.1:8091 (pid <some number>).

If you instead see:
    Backend already running (pid <number>).
-> that means it is already running, no action needed.


--- Check it is healthy (do this every time, before using the app) ---
Type:
    curl http://127.0.0.1:8091/api/health

Expected output:
    {"status":"ok","service":"nms-inventory-api"}

If you do NOT see "ok", run:
    bash run_backend.sh logs
and read the last lines to see the error.


====================================================
STEP 2: Open the Application in a Browser
====================================================
This part is NOT a terminal command. Open your web BROWSER
(Chrome/Firefox/Edge) and go to this address bar (not bash):

    http://127.0.0.1:8091

The Inventory, Dashboard, and Device Config pages will load data
automatically from the same address - no separate frontend server
or extra port is needed.

If the page looks outdated after a code update, do a hard refresh in
the browser: Ctrl + Shift + R


--- Sharing with a teammate (no code pulling needed) ---
The app now listens on all network interfaces (0.0.0.0), so a teammate
on the SAME corporate network/VPN as this machine can open it directly
in their own browser using this machine's network IP instead of
127.0.0.1:

    http://10.237.67.2:8091

Requirements:
  - Teammate must be on the same network/VPN as this machine
    (hostname: zuni-dev-01).
  - Port 8091 must not be blocked by a firewall in between. If they
    cannot connect, an admin may need to run on this machine:
        sudo firewall-cmd --add-port=8091/tcp --permanent
        sudo firewall-cmd --reload
  - This shares the live running app only - it does not give them any
    code, files, or terminal access.


====================================================
STEP 3: Everyday Use - Quick Status Check
====================================================
Whenever you reopen your laptop/terminal and want to check if the app
is still running, type:

    bash /home/ad39013/NMS_APP/backend/run_backend.sh status
    curl -o /dev/null -s -w "%{http_code}\n" http://127.0.0.1:8091/index.html

- Status should say "Backend running (pid ...)".
- The second command should print 200.

If not running / not 200, repeat Step 1.


====================================================
STEP 4: Stopping the App (when you are done)
====================================================
Type:
    bash /home/ad39013/NMS_APP/backend/run_backend.sh stop


====================================================
STEP 5: Restarting After a Code Change
====================================================
If a developer/AI updates the backend or frontend code, restart with:

    bash /home/ad39013/NMS_APP/backend/run_backend.sh restart

Then in the browser, do a hard refresh: Ctrl + Shift + R
